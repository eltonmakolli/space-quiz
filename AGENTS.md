# Project rules

- Keep the quiz dependency-free and runnable by opening `index.html` directly.
- Keep the experience in the single `index.html` file unless a future change clearly needs new files.
- Preserve the 10-question flow, progress bar, score tracking, feedback states, and results screen.
- Use semantic HTML, keyboard-accessible controls, visible focus states, and readable contrast in both themes.
- Match the existing polished, colorful mission-control visual style and support `prefers-color-scheme`.
- After UI or interaction changes, smoke-test the page in the integrated browser, including keyboard navigation and the affected quiz flow.
